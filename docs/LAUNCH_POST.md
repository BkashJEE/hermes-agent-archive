## Follow-up / longer post

I wanted a place to find what people are actually doing with Hermes—and trace each example back to its source.

Hermes Agent Archive collects community stories, documentation examples and projects in a searchable dashboard. It runs locally with Node.js and `npm start`: no dependency installation, build step or API keys needed to browse.

The original site code is MIT licensed. Quoted content keeps its original credits and source rights. Anyone can fork the code or propose a change; I review what gets published to the shared dashboard.

A few deliberate limits:

- This is independent of Nous Research and is not a complete directory.
- Repository cards require more than 50,000 verified GitHub stars and documented Hermes support. That excludes many smaller projects; it is a selection rule, not a quality guarantee.
- Trending uses measured star growth between API snapshots. Jev usefulness labels are automated editorial assessments, not votes or proof that a workflow works.
- Importer coverage and some shelves are still being completed. Corrections and critical feedback are welcome.

Browse: https://hermes-agent-archive.vercel.app
