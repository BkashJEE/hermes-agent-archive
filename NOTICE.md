# Attribution and rights

Hermes Agent Archive is an independent community project maintained by BkashJEE. It is not an official Nous Research product and does not imply endorsement by Nous Research, quoted authors or listed projects.

## What the MIT license covers

`LICENSE` covers original code and original documentation contributed to this project. It does not grant rights to third-party quotations, imported documentation, screenshots of third-party material, names, logos or trademarks. Those materials retain their source rights. A public URL and an author credit are attribution, not a claim of blanket permission to redistribute the source.

## Sources

- **Official Hermes documentation and examples:** Nous Research's [Hermes Agent repository](https://github.com/NousResearch/hermes-agent), with its [MIT notice retained locally](assets/licenses/hermes-agent.txt). Entries link to the relevant documentation; some carry a pinned source file and revision. The repository license does not establish rights to every third-party quotation appearing in its docs.
- **Community stories:** quotes and credits collected from [Nous Research's user-stories page](https://hermes-agent.nousresearch.com/docs/user-stories). Original authors and source permalinks remain attached to each entry. A reported outcome is a user's account, not an independently reproduced result.
- **Jev directory imports:** source links are retained in imported records from [the builder directory](https://www.jev-use-cases.com). Importing a record does not transfer rights to its text or establish its engagement claims as public API metrics.
- **Repository descriptions and public metrics:** GitHub, Hacker News and Reddit sources are identified in the data. API snapshots are observations, not continuously live counts.
- **My Work:** the maintainer's posts and explicitly credited analytics. These figures are not public API evidence and must not be used as public popularity signals.
- **Fonts:** Inter and JetBrains Mono are requested from Google Fonts. Font files are not bundled in this repository. Font requests contact Google; see [privacy and data handling](docs/PRIVACY.md).

Check source-specific terms before reusing archive content in another publication. Do not assume that the entire JSON dataset has the same license as the site code.

## Corrections and rights concerns

Use the [correction form](https://github.com/BkashJEE/hermes-agent-archive/issues/new?template=correction.yml) for public attribution, accuracy or rights concerns. Give the entry ID or URL and the correction requested. If the report contains private information, request a private contact without posting the information itself.

Normal importers preserve archived entries for reproducibility. A request to redact or remove material is handled explicitly by the maintainer; an importer must not silently delete records or silently restore material withdrawn after review. This project does not promise that copying a public repository can later be undone in every fork or cache.
