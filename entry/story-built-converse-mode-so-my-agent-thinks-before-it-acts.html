Built converse mode so my agent thinks before it acts

By @ibrandis · Discord

My Hermes agent used to start executing the moment I hit enter. I'd describe a vague idea and it would immediately start writing files, calling tools, making changes I hadn't fully thought through yet. So I built converse mode. One plugin, two commands. The agent won't touch a single tool until you say so.

— @ibrandis, via Discord.
