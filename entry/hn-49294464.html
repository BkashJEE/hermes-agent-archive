$0. but I use at least $8,000 worth of monthly tokens.

I used to have:
$200 Claude-max
$10 github copilot
$20 chatgpt
$20 Cursor

---

then, I spent roughly $5000 in tokens for a project which turned out to be a dud.
Figured, inference wasn't going anywhere as its now 80% of my day. So, I built a 4x DGX Spark cluster and put GLM5.2 on it. Then put a few qwen models for vision and embedding purposes on my original DGX Spark and completely went local. Tron, my Hermes agent, uses agent storming to orchestrate openCode agents and hermes subagents to handle most of my daily tasks.

For fun, I reworked a public Github vLLM Dashboard to track my usage and cloud cost avoided.
original dashboard was by github.com/niklasfrick but I extended it.
github.com/Wpnx330/spark-dashboard
