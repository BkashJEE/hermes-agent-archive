Multica workspace with a Hermes runtime

By multica-ai · GitHub

Assign work to an installed Hermes CLI through a shared agent workspace.

- Setup: Set up a Multica runtime on a host where Hermes is already installed and authenticated, then select Hermes for an agent.
- Limitations: Multica does not supply the agent CLI. It is source-available; inspect its license, permissions and runtime isolation before adopting it.
- Review scope: upstream documentation was read. The archive has not installed or execution-tested this integration.
