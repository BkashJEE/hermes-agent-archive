colbymchenry/codegraph

A code index with an installer that configures the Hermes MCP connection.

By colbymchenry · GitHub

WHAT IT DOES
CodeGraph maintains a code index that agents can query through MCP. Its installer explicitly detects Hermes and configures the connection.

HOW TO USE IT
Install the CLI, open a new terminal, and run codegraph install to connect Hermes. Run codegraph init inside each project to build its index. Restart Hermes to load the MCP server. Installing the CLI alone does not configure the agent or index a project.

USE CASE
Ask Hermes to investigate relationships in an unfamiliar repository using the project index. This is an archive-authored example; token and speed savings are not measured here.

npm install -g @colbymchenry/codegraph
# In a new terminal:
codegraph install
# From the project you want to index:
codegraph init
