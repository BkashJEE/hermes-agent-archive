Write a concise briefing with source URLs

Turn recent articles into three short news summaries with links.

By Nous Research · Official Docs

Official documentation example from Nous Research. The copyable prompt below preserves the source wording.

- How to use: Paste as a one-off task, or use the text as a scheduled job body. It requires web search and does not create a schedule by itself.
- Customize example names, paths and topics before running it.
- This is a documented example, not a claim of measured popularity.

Search the web for the latest news about AI agents and open source LLMs.
Find at least 5 recent articles from the past 24 hours. Summarize the
top 3 most important stories in a concise daily briefing format. For each
story include: a clear headline, a 2-sentence summary, and the source URL.
Use a friendly, professional tone. Format with emoji bullet points.
