If you use hermes setup

From Official Docs

Setup requests declared Python extras through PM. It cannot override their Python-version or platform markers: The declared neutts dependency requires Python below 3.14. The Hermes runtime requires Python 3.14, so requesting this extra does not install NeuTTS there. Choose a compatible provider. A separately managed NeuTTS command provider needs its own supported Python environment. Select another provider if a dependency cannot run on your platform.
