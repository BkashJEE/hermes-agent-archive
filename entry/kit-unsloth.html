Launch Hermes with local models through Unsloth.

By unslothai · GitHub

WHAT IT DOES
Unsloth documents agent launchers and compatible model-serving APIs, including an explicit Hermes launcher. Its broader training and model tooling is not Hermes-specific.

HOW TO USE IT
Install Unsloth and configure a supported local model using its upstream instructions. Then use the Hermes launcher below. Model and hardware setup are prerequisites, not handled by this archive.

USE CASE
Try a local model with a Hermes workflow after setting up the model in Unsloth. This is an archive-authored example; performance depends on the selected model and machine.

unsloth start hermes
