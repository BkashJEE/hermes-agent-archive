Quick overview

From Official Docs

Drop a directory into ~/.hermes/plugins/ with a plugin.yaml and Python code: Start Hermes - your tools appear alongside built-in tools. The model can call them immediately.

From the official Hermes Agent documentation.

~/.hermes/plugins/my-plugin/
├── plugin.yaml      # manifest
├── __init__.py      # register() — wires schemas to handlers
├── schemas.py       # tool schemas (what the LLM sees)
└── tools.py         # tool handlers (what runs when called)
