Let Hermes choose document sections before retrieving pages

A community demo uses a document hierarchy and targeted tools instead of nearest-vector chunks.

By @lemoussel · Discord

The agent first understands how the document is organized, then decides which pages to inspect before answering.

— @lemoussel, 2026-05-06, via the public Nous Discord archive.

The contributor indexes a PDF with PageIndex, waits for indexing, then gives Hermes a toolset dedicated to that document. The agent inspects the hierarchy and chooses relevant pages before answering. This records the retrieval technique, not a recommendation or popularity claim for the project.

Limitations: A custom demonstration, not a built-in Hermes feature or a benchmark against other retrieval systems. It requires indexing and document-specific tools; the workflow has not been execution-tested here.

Documentation check: this specific community technique was not found in the official English reference snapshot (5458de9) or the cached prompt guides. Related built-in features are documented. This is a bounded source review, not a claim about every document or independent execution testing.
