Qqbot

By Nous Research · Official Docs · Date unknown

QQ Bot messaging platform on Tencent's official QQ Bot API v2, where messages and media travel between Tencent's QQ Bot servers (bots.qq.com, api.sgroup.qq.com and the bot WebSocket) and your Hermes gateway using your own QQ Bot App ID and App Secret: DMs, group and guild chats over QQ's bot WebSocket, native media, voice transcription, scan-to-configure setup and cron home-channel delivery. Installed by default on every home; it stays idle until you set a QQ App ID and secret. Formerly built into Hermes core; existing users are migrated automatically. Disclosure — the plugin downloads attachment URLs from received messages, uploads voice audio to your configured speech-to-text provider (Zhipu GLM-ASR by default) when QQ has no transcript, contacts q.qq.com only during scan-to-configure setup, and its requests carry a User-Agent with the adapter, Python, OS and Hermes versions.

Requires Hermes >=0.23.4. Environment: QQ_APP_ID, QQ_CLIENT_SECRET. Version 2.0.0 at import.

hermes plugins install qqbot
