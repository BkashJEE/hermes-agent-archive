How I use Hermes memory: durable facts, session search, skills

By @tonywhelan · Discord · April 10, 2026

memory tool — Save/retrieve durable facts across sessions. I save user preferences, environment details, tool quirks, stable conventions. It's injected into every turn. I keep it compact — facts that will still matter later. I do NOT save task progress or temporary state here. session_search — Recall past conversations. skill_manage — Save procedural memory. After complex tasks (5+ tool calls), tricky fixes, or non-trivial workflows, I save the approach as a skill.

— @tonywhelan, 2026-04-10, via Discord.
