A documented Hermes launcher for more concise agent output.

By JuliusBrussee · GitHub

WHAT IT DOES
Caveman provides a CLI wrapper and concise-output workflow. The README explicitly documents Hermes integration through a custom provider and environment configuration.

HOW TO USE IT
Install the CLI, complete its setup, then launch Hermes using caveman hermes. Read the upstream setup notes for your provider.

USE CASE
Keep routine task responses short when verbose explanations make repeated runs harder to scan. This is an archive-authored example.

EVIDENCE
The archive verifies the documented integration, not the project’s claimed token savings. No savings figure is presented as a measured result here.

npm install -g @caveman-ai/cli
caveman setup --install
caveman hermes
