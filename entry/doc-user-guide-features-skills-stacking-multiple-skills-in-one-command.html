Stacking multiple skills in one command

From Official Docs

You can invoke several skills in a single message by chaining slash commands at the start - every leading /skill token (up to 5) is loaded, and the rest becomes your instruction: Parsing stops at the first token that isn't an installed skill, so arguments that happen to start with / (like file paths) are never swallowed: For combinations you use repeatedly, prefer a skill bundle - same effect under one short command. (Plan mode works the same way but is a built-in command now: /plan [request] tells Hermes to inspect context if needed, write a markdown implementation plan instead of executing the task, and save the result under .hermes/plans/ relative to the active workspace/backend working directory.)
