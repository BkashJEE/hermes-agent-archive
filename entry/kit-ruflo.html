A meta-harness: agent teams, memory, verification and cost control layered over a harness.

By ruvnet · GitHub

WHY
One agent doing everything hits a ceiling. Ruflo's framing is "Agent = Model + Harness" and it sells the layer above: planning, memory, agent teams, plugins, cost accounting and verification, with a fourteen-chapter guide explaining the progression from a first task to a working team.

HOW
Install from npm (ruflo). Start with a single task, then add memory and teams as the work justifies it — the documentation is explicitly staged that way.

USE CASE
Work that needs several roles — someone to plan, someone to implement, someone to check — and a record of what each cost.

Caveat, stated plainly: the README describes it as a meta-harness "for Claude Code and Codex" and does not name Hermes Agent. It is here for the pattern, not for a verified Hermes integration.
