Home Assistant

By Nous Research · Official Docs

Home Assistant gateway platform (state-change events in, persistent notifications and cron notify delivery out) plus the homeassistant toolset (ha_list_entities, ha_get_state, ha_list_services, ha_call_service). Formerly built into Hermes core; existing users are migrated automatically.

Requires Hermes >=0.21.5. Tools: ha_list_entities, ha_get_state, ha_list_services, ha_call_service. Environment: HASS_TOKEN. Version 2.0.1 at import.

hermes plugins install homeassistant
