Bridge a serial terminal to Hermes with a minimal login shell

A community hardware experiment connects a serial getty to a shell backed by Hermes.

By @hugh1979 · Discord

Hooked the shell up to an autologin getty on a serial port.

— @hugh1979, 2026-04-23, via the public Nous Discord archive.

The contributor built a minimal login shell that talks to Hermes through the gateway web service or hermes chat, then connected that shell to a serial getty. This let a physical teletype act as the input/output device without using the normal terminal interface.

Limitations: A niche hardware experiment requiring a custom shell and serial setup. Autologin grants access to the attached session, so use a dedicated restricted account and control physical access. The standard CLI and API are documented; the serial-terminal bridge is the discovery.

Documentation check: this specific community technique was not found in the official English reference snapshot (5458de9) or the cached prompt guides. Related built-in features are documented. This is a bounded source review, not a claim about every document or independent execution testing.
