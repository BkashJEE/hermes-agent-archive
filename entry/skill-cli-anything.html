HKUDS/CLI-Anything

An experimental community Hermes skill for building CLI harnesses around software.

By HKUDS · GitHub · September 25, 2026

WHAT IT DOES
CLI-Anything documents a community Hermes skill that adapts its harness-building workflow to Hermes tools, including file operations and terminal execution.

HOW TO USE IT
Clone the repository and run its Hermes installer, then restart Hermes. The installer uses the active HERMES_HOME skills directory, falling back to ~/.hermes/skills.

USE CASE
With a local checkout of the target application, ask Hermes to build a CLI harness for that application or refine an existing harness for a specific workflow. This is an archive-authored example.

STATUS
The upstream project labels this Hermes integration experimental and community-maintained.

git clone https://github.com/HKUDS/CLI-Anything.git
bash CLI-Anything/hermes-skill/scripts/install.sh
