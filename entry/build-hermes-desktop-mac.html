dodo-reach/hermes-desktop

A Mac app that manages Hermes locally or on another machine over plain SSH, with no gateway and no exposed port.

By dodo-reach · GitHub

WHY
Running Hermes on a second machine usually means exposing something. This connects over SSH instead, so nothing new listens on the network.

HOW
Direct-local mode when Hermes is installed on the same Mac; SSH mode for another host. Sessions Chat, terminal resume and workflow launch need the `hermes` CLI present on whichever machine is running it. Distributed as a zipped app; first launch needs right-click → Open, which the README notes does not disable Gatekeeper and does not need sudo.

USE CASE
Your agent lives on a server or a spare machine and you want a real window onto it rather than an SSH session.

Verified: the README documents both modes and states that no gateway or exposed port is involved.
