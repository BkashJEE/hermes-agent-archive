Archify diagrams with Hermes

Turn a repository or workflow description into an interactive architecture diagram through a documented Hermes skill.

By tt-a1i · GitHub

Create an interactive architecture or workflow diagram through Archify’s community Hermes skill.

- Setup: Install Node.js 18 or newer, inspect the published skill, then use the upstream installation command below and restart Hermes. Ask the archify skill to map the repository’s runtime architecture and return the specification JSON and HTML file paths.
- Limitations: Skill-only community integration, not an official Nous Research product. The renderer remains a Node CLI; it adds no native Python render tools and is not an agent-switcher target. Generated diagrams are not verification of live infrastructure or merge safety.
- Docker: Install into the mounted Hermes skills volume or mount the actual skill files. A host symlink pointing outside that volume is not visible inside the container.
- Review scope: upstream README and dedicated Hermes integration instructions were read; the archive has not installed or execution-tested this integration.

hermes skills install skills-sh/tt-a1i/archify/archify -y
