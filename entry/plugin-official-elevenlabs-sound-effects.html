ElevenLabs Sound Effects

By Nous Research · Official Docs · Date unknown

ElevenLabs sound effects for Hermes: one tool, elevenlabs_sound_effect, that turns a text description ("glass shattering on a tile floor", "90s hip-hop drum loop, 90 BPM") into an audio file, 0.5 to 30 seconds, optionally a seamless loop, and sends it to you in chat. Bundles a sound-design skill with a local ffmpeg script (trim, loudness, mono, loop fixing, game variation packs) and, in Hermes Desktop, an inline sound card and a sound library tab. Model, audio format and endpoint are plugin settings. Disclosure: uses your ElevenLabs API key (ELEVENLABS_API_KEY, the same key as Hermes's ElevenLabs voice; a restricted key needs the Sound Effects permission); every call is a paid generation billed to your ElevenLabs account. Only the sound description and its parameters are sent, to api.elevenlabs.io (or the data-residency endpoint you set). Files are written to cache/generated/audio under the Hermes home and never overwritten. One Python dependency (httpx, already part of Hermes).

Requires Hermes >=0.22.0. Tools: elevenlabs_sound_effect. Environment: ELEVENLABS_API_KEY. Version 1.2.0 at import.

hermes plugins install elevenlabs-sound-effects
