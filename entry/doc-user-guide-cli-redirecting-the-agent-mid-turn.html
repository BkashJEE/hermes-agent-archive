Redirecting the Agent Mid-Turn

From Official Docs

While the agent is working, you can send a correction without starting a new turn: Type a new message + Enter - redirects the active turn using your correction Ctrl+C - interrupt the current operation (press twice within 2s to force exit) Completed tool work and reasoning already shown stay in context A running tool reaches its safe boundary before the correction is applied
