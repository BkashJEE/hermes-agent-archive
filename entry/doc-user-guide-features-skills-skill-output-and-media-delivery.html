Skill output and media delivery

From Official Docs

When a skill response (or any agent response) includes a bare absolute path to a media file - for example /home/user/screenshots/diagram.png - the gateway auto-detects it, strips it from the visible text, and delivers the file natively to the user's chat (Telegram photo, Discord attachment, etc.) instead of leaving the raw path in the message. For audio specifically, the [[audio_as_voice]] directive promotes audio files to native voice-message bubbles on platforms that support them (Telegram, WhatsApp).
