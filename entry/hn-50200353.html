So I set out to build ClusterMob, a community registry of Hermes profiles and profile packs

By k_sze · Hacker News · October 22, 2026

I was reading the Hermes documentation page on profile distributions and, to my surprise, found that there is no official registry, no central mechanism for profile discovery.

So I set out to build ClusterMob, a community registry of Hermes profiles and profile packs.

After you register, you can register profiles by providing the git repo URL. The git repo will then be examined to automatically extract relevant metadata. There is also a background worker that performs security scanning on the git repo (to check for malicious instructions, etc.).

Any authenticated user can register any git repo on GitHub/Bitbucket/GitLab. There is a mechanism for the actual author of the git repo to claim authorship.

Note that the git repo doesn't need to follow the official Hermes profile distribution format.

— k_sze, 2026-10-22, in the Hacker News thread “ClusterMob – a community registry of Hermes Agent profiles”.
