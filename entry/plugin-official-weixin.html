Weixin

By Nous Research · Official Docs · Date unknown

Weixin (personal WeChat) messaging platform over Tencent's iLink Bot API: QR login in `hermes gateway setup`, DMs with pairing or allowlists, native images, video, voice and documents through the encrypted CDN, and cron home-channel delivery (deliver=weixin). Installed by default on every home; it stays idle until you log in. Formerly built into Hermes core; existing users are migrated automatically. Disclosure — messages and media travel between Tencent's iLink servers (ilinkai.weixin.qq.com, novac2c.cdn.weixin.qq.com) and your Hermes gateway using the bot token from your own QR login, which is saved in your profile's .env and weixin/accounts/. The plugin also downloads image URLs that appear in replies so it can send them as native media.

Requires Hermes >=0.22.3. Environment: WEIXIN_ACCOUNT_ID, WEIXIN_TOKEN. Version 2.0.0 at import.

hermes plugins install weixin
