Eynzof/Hermes-CN-Desktop

A Windows-first Hermes desktop app built with Tauri, Rust and TypeScript, aimed at Chinese-language users.

By Eynzof · GitHub

WHY
Most Hermes front-ends assume macOS or Linux and English. This one leads with a Windows x64 installer and a Chinese interface.

HOW
Ships a signed Windows installer. For local dashboard development it expects either Hermes-CN-Core or a Hermes CLI already installed on the machine.

USE CASE
Running Hermes on Windows without building from source, or working in Chinese.

Verified: the README lists the Windows x64 installer by filename and names its Hermes CLI dependency.
