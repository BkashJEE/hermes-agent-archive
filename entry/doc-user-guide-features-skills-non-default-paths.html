Non-default paths

From Official Docs

If your skills don't live under skills/ (common when you're adding a skills/ subtree to an existing project), edit the tap entry in ~/.hermes/skills/.hub/taps.json : The hermes skills tap add CLI defaults new taps to path: "skills/" ; edit the file directly if you need a different path. hermes skills tap list shows the effective path per tap.
