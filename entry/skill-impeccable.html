Design guidance and critique skills packaged for Hermes.

By pbakaus · GitHub

WHAT IT DOES
Impeccable packages design guidance and commands for auditing, critiquing and polishing interfaces. Its README documents a Hermes distribution and command routing through /impeccable.

HOW TO USE IT
Use the installer below for a global Hermes installation, then reload Hermes. For project-local installation instead, the README requires running hermes skills trust from the project root.

USE CASE
Ask Hermes to audit a settings screen, prioritize readability problems, and apply a focused polish pass. This is an archive-authored example.

LIMITATION
The skill works in Hermes, but the project’s automatic design edit hook does not run there.

npx impeccable install --providers=hermes --scope=global
