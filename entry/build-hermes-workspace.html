outsourc-e/hermes-workspace

A web workspace for Hermes — chat, terminal, memory, skills and an inspector — that attaches to the agent you already run.

By outsourc-e · GitHub

WHY
Hermes runs in a terminal, which is where the work happens and not where you want to read a long session back. This is a browser workspace over the same agent: chat, terminal, memory, skills and a request inspector in one place.

HOW
Its README documents two paths. If you already run Hermes Agent, attach to it — the project advertises about a minute for that. Otherwise its install script fetches hermes-agent through Nous's own installer, clones the repo, writes .env and installs dependencies. You then run `hermes gateway run` alongside it.

USE CASE
You want to read back what the agent did without scrolling a terminal, or hand a session to somebody who will not use a CLI.

Verified: the README states v2 runs on vanilla NousResearch/hermes-agent without forking it.
