Hermes Command Center

Inspect Hermes health, activity, scheduled jobs, model usage, skills and memory from a Desktop dashboard.

By Cliff Wade · GitHub

Cliff Wade describes a read-only dashboard using local Hermes state to show processes, model usage, cron jobs, plugins, skills and memory. Its Desktop page uses /hermes-center so it can coexist with the host's built-in Command Center.

Follow the repository's instructions to install and enable the backend plugin, then install the Desktop UI plugin. Restart the backend so its API routes are mounted, reload Desktop plugins and open Hermes Center from the sidebar.

Requires Hermes Desktop and its plugin SDK. The author's read-only and no-telemetry claims have not been independently audited. No candidate code was installed or executed during archive review.
