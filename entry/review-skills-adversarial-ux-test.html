Adversarial Ux Test

By Omni @ Comelse · Official Docs

Roleplay a hostile user to find and triage UX pain points.

Exercise a product as a difficult or confused user and record reproducible friction. Supply the test surface and account; simulated testing does not substitute for real user research.
Install the official optional skill with the command below, then start a new session. Platforms: linux, macos, windows.
