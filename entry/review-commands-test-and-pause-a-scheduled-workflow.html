Test and pause a scheduled workflow

By Nous Research · Official Docs

Use the documented recipe to test and pause a scheduled workflow.

Run on the configured Hermes host and replace example paths, IDs and destinations. Read the linked prerequisites before pasting; commands that send messages, approve changes or restart services have real effects.

Source: official Hermes Agent documentation. This card is an editorial summary; copyable examples retain source wording. Verify the linked instructions for your installed version.

# List all active jobs
/cron list

# Trigger a job immediately (for testing)
/cron run <job_id>

# Pause a job without deleting it
/cron pause <job_id>

# Edit a running job's schedule or prompt
/cron edit <job_id> --schedule "every 4h"
/cron edit <job_id> --prompt "Updated task description"

# Add or remove skills from an existing job
/cron edit <job_id> --skill arxiv --skill obsidian
/cron edit <job_id> --clear-skills

# Remove a job permanently
/cron remove <job_id>
