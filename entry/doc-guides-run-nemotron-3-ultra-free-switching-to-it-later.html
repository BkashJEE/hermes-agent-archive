Switching to it later

Already set up with another model?

From Official Docs

Already set up with another model? Desktop app: open the model picker, search for nemotron 3 ultra , and select the Free tier variant. CLI / TUI: switch any time from inside a session with /model nvidia/nemotron-3-ultra:free , or run /model to open the picker and choose it from the list.
