Agent Merge Conflict Arbiter

By Hermes Agent · Official Docs

Neutral arbiter for merge conflicts between two agents.

Compare both agents’ changes against the intended task before resolving a conflict. Requires access to the conflicting working trees; review the proposed merge and run tests.
Install the official optional skill with the command below, then start a new session. Platforms: linux, macos, windows.
