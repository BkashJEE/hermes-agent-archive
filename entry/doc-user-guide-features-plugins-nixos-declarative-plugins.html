NixOS declarative plugins

From Official Docs

On NixOS, plugins can be installed declaratively via the module options - no hermes plugins install needed. See the Nix Setup guide for full details. Declarative plugins are symlinked with a nix-managed- prefix - they coexist with manually installed plugins and are cleaned up automatically when removed from the Nix config.

From the official Hermes Agent documentation.

services.hermes-agent = {
  # Directory plugin (source tree with plugin.yaml)
  extraPlugins = [ (pkgs.fetchFromGitHub { ... }) ];
  # Entry-point plugin (pip package)
  extraPythonPackages = [ (config.services.hermes-agent.package.python.pkgs.buildPythonPackage { ... }) ];
  # Enable in config
  settings.plugins.enabled = [ "my-plugin" ];
};
