thedotmack/claude-mem

Compresses what happened into context that survives the next session.

By thedotmack · GitHub

WHY
Long agent sessions end and take their working knowledge with them. claude-mem is a persistent memory compression system: rather than replaying a transcript, it compresses sessions into retrievable context and injects the relevant part back when it matters.

HOW
Install it beside the harness and let it capture sessions; it exposes search tools over the compressed store. The repo documents a quick start, how it works, and its search tools.

USE CASE
Multi-day work on one feature, where the context that matters was established on day one and the agent no longer has it on day three.

Caveat, stated plainly: the README says "built for Claude Code". The GitHub description claims it works with Hermes among others, but the project's own documentation leads with a different harness — check it against your setup before relying on it.
