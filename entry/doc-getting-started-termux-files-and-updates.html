It prints the package-manager command instead. Canary versions contain ~canary.<timestamp> and sort before the corresponding stable version. Each suite only lists its own channel's packages; to move between channels, edit the channel path and suite in hermes-agent.list , then pkg update && pkg upgrade hermes-agent .
