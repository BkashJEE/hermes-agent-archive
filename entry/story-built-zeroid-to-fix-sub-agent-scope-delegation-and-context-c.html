Built ZeroID to fix sub-agent scope delegation and context costs

By @justin_albrethsen · Discord

One of the problems I run into with Hermes is high cost when context windows fill up. One method to fix this is heavy use of sub-agents, but permissions/scope delegation to the sub-agent is often problematic. ZeroID is an agent identity layer that uses RFC 8693 token exchange to handle scope delegation with sub-agents.

— @justin_albrethsen, via Discord.
