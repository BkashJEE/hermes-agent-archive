farion1231/cc-switch

One desktop app to manage every harness you run — and it names Hermes Agent in its own headline.

By farion1231 · GitHub

WHY
Running more than one agent harness means more than one config, more than one set of provider keys, and no single place to see what is pointed where. cc-switch is a Tauri desktop app whose stated job is managing exactly that spread — its README headline lists Claude Code, Claude Desktop, Codex, Gemini CLI, Grok Build, OpenCode, OpenClaw, Hermes Agent and MiniMax Code by name.

HOW
Install the desktop release for your platform, point it at the harnesses already on your machine, and switch the active provider or profile from one window instead of editing each harness's own config file.

USE CASE
You run Hermes for long-lived agent work and something else for quick edits. Instead of hand-editing two config files whenever you change provider, you flip it in one place and both follow.

Verified: Hermes Agent is named in the project's own README headline.
