Schedule an AI news briefing for Telegram

Ask Hermes to schedule a morning briefing and deliver source links to Telegram.

By Nous Research · Official Docs

Official documentation example from Nous Research. The copyable prompt below preserves the source wording.

- How to use: Connect the Telegram gateway first. Replace the topic, delivery channel and 8am schedule; specify your timezone. This prompt creates a recurring job.
- Customize example names, paths and topics before running it.
- This is a documented example, not a claim of measured popularity.

Every morning at 8am, search the web for the latest news about AI agents
and open source LLMs. Summarize the top 3 stories in a concise briefing
with links. Use a friendly, professional tone. Deliver to telegram.
