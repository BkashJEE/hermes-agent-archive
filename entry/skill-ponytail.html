DietrichGebert/ponytail

A Hermes plugin for focused implementation, review and technical-debt work.

By DietrichGebert · GitHub

WHAT IT DOES
Ponytail documents a Hermes plugin that supplies the active mode before each model turn and exposes its own review, audit and debt commands.

HOW TO USE IT
Install the plugin, restart Hermes, then invoke /ponytail-help to inspect the available commands. /ponytail-review and /ponytail-debt provide starting points for review and cleanup.

USE CASE
Review a working feature for unnecessary code, then identify a small cleanup you can verify independently. This is an archive-authored example.

LIMITATION
The active runtime mode is process-local; do not assume it persists across a Hermes restart.

hermes plugins install DietrichGebert/ponytail --enable
