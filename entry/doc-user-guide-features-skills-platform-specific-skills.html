Platform-Specific Skills

From Official Docs · September 25, 2026

Skills can restrict themselves to specific operating systems using the platforms field: Value Matches macos macOS (Darwin) linux Linux windows Windows When set, the skill is automatically hidden from the system prompt, skills_list() , and slash commands on incompatible platforms. If omitted, the skill loads on all platforms.

From the official Hermes Agent documentation.

platforms: [macos]            # macOS only (e.g., iMessage, Apple Reminders, FindMy)
platforms: [macos, linux]     # macOS and Linux
