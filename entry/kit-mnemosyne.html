mnemosyne-oss/mnemosyne

A SQLite-backed memory layer that calls itself Hermes-first and ships its Hermes plugin enabled by default.

By mnemosyne-oss · GitHub

WHY
Agent memory usually means a cloud service and another account. This keeps it in SQLite on your own machine, with one pure-Python dependency.

HOW
It reaches Hermes two ways — MCP and a plugin — and its own compatibility table marks the Hermes integration "Native, ships enabled" while other harnesses need setup. Its data directory defaults to ~/.hermes/mnemosyne/data, which is a fair indication of which harness it was built around.

USE CASE
You want the agent to remember across sessions without sending that memory anywhere.

Verified: the README describes it as "a universal, Hermes-first memory layer" and documents the Hermes plugin in its own section.
