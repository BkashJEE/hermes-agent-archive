nexu-io/open-design

Connect a local design engine to Hermes through MCP.

By nexu-io · GitHub

WHAT IT DOES
OpenDesign exposes a design engine through its CLI and MCP integration. Its support table includes a dedicated Hermes configuration command.

HOW TO USE IT
Install OpenDesign and its od CLI using the upstream instructions for your platform. Then run the command below to configure the Hermes MCP connection. This command connects an existing installation; it does not install OpenDesign itself.

USE CASE
Ask Hermes to create a prototype or presentation artifact using the connected design tools. This is an archive-authored example.

SETUP NOTE
The README provides platform-specific installation instructions; follow those before configuring the connection.

od mcp install hermes
