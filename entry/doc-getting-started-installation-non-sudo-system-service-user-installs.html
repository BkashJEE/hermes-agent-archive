Non-Sudo / System Service User Installs

From Official Docs

Run the source installer as the intended service user. Its home, tool store, configuration, and launcher must belong to that user. As an administrator, install the source-build prerequisites and any Linux libraries needed by the selected browser backend. As the service user, run the regular installer: Add the actual launcher directory to the service user's shell environment: Run hermes doctor from that account. Use the installed wrapper, not a hardcoded venv/bin/hermes path. For a Linux user service that must survive logout, enable lingering as an administrator: The current source installer does not run Playwright's --with-deps step or provide a package-manager-specific sudo fallback. PM manages tool binaries; the administrator supplies system libraries. See Browser automation and Messaging Gateway .
