Hermes Desktop Achievements

View achievements, progress and goals in Hermes Desktop, with optional unlock notifications and share cards.

By Tony Simons (original), extended by Cliff Wade · GitHub

Originally created by Tony Simons and extended by Cliff Wade, this Desktop plugin displays badges, goals, records, rewards and custom achievements using the existing hermes-achievements backend through the Hermes plugin SDK.

Enable the hermes-achievements backend, install the Desktop UI plugin following the repository instructions, then reload Desktop plugins and open Achievements. The author recommends Hermes Desktop v0.19 or newer. The matching backend must be available and enabled.

Optional Discord announcements send unlock information to a configured webhook; leave them disabled unless you want that information shared. The archive reviewed documentation only and did not install or execute the plugin. Original-author credit is preserved from the repository's License section.
