MCP Serve

By Nous Research · Official Docs · Date unknown

Run Hermes as an MCP server: `hermes mcp-serve` lets any MCP client (Claude Code, Claude Desktop, Cursor, Codex) list and read your messaging conversations, poll live events, send messages and answer approvals over stdio. `--tools` (off by default) also exposes Hermes' web, browser, vision, image generation, skills and TTS tools; terminal, file and kanban tools are never exposed. Formerly built into Hermes core as `hermes mcp serve` (MCP clients change their args to ["mcp-serve"]). Disclosure — the connecting MCP client reads the active profile's conversation history (state.db) and can send messages as your connected platform accounts; with `--tools` it also runs Hermes tools under your configured provider credentials, which can spend provider credits. The plugin itself makes no network or model calls beyond those tool calls and sends.

Requires Hermes >=0.22.0. Version 1.0.0 at import.

hermes plugins install mcp-serve
