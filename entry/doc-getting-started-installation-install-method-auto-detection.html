The update owner depends on the running installation, not only its data home. Source checkouts use the managed Git update path. Desktop bundles, Docker, Nix, and Termux packages retain their package owner's update mechanism. hermes doctor reports installation provenance. See Updating & Uninstalling before changing package-owned files.
