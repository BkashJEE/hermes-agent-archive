Xchat

By Nous Research · Official Docs

X Chat gateway platform: talk to Hermes in X's end-to-end encrypted DMs. Hermes runs as the X account you connect: chat with it in your own self-chat ("message yourself"), or give it a separate account and DM that. Messages are decrypted and encrypted locally with X's official Chat XDK, so X only routes ciphertext. Encrypted media, threaded replies, group mention gating and cron delivery.

Requires Hermes >=0.21.5. Environment: XCHAT_ACCESS_TOKEN. Version 0.1.0 at import.

hermes plugins install xchat
