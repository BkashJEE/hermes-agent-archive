Blind since birth, I built an NVDA translator addon with Nous

By @denis_skripnik · Discord

I have been blind since birth. I use a screen reader program. It vocalizes all my actions. Today I created an add-on that translates texts into the languages I need by pressing Insert+Shift+T (selected text), Insert+Shift+Y - from the clipboard. Now I translated this text using Nous! Thank you for this opportunity!

— @denis_skripnik, via Discord.
