Hermes Desktop Theme Pack

Browse and apply Hermes skins across the CLI, TUI, Desktop and web dashboard.

By Cliff Wade · GitHub

Cliff Wade's theme pack provides YAML skins and a Theme Switcher for Hermes Desktop and the web dashboard. Preview themes, search for a palette, switch between light and dark counterparts, and apply a skin across Hermes surfaces.

To use the skins, follow the repository's installation instructions and select one through Hermes Appearance settings or /skin. The full switcher requires both its backend plugin and its Desktop UI plugin. With an SSH connection, install the backend on the remote host and the UI on the local Desktop computer; restart or reconnect the backend to mount its routes.

The author's accessibility and contrast claims have not been independently tested by this archive. Community theme credits are listed upstream, including BeardedChop/hermes-skins-pack. This listing is a documentation review, not a security audit or runtime endorsement.
