Resuming Sessions

From Official Docs · September 25, 2026

When you exit a CLI session, a resume command is printed: Resume options: Resuming restores the full conversation history from SQLite. The agent sees all previous messages, tool calls, and responses - just as if you never left. Use /title My Session Name inside a chat to name the current session, or hermes sessions rename <id> <title> from the command line. Use hermes sessions list to browse past sessions.
