Suspending to Background

From Official Docs · September 25, 2026

On Unix systems, press Ctrl+Z to suspend Hermes to the background - just like any terminal process. The shell prints a confirmation: Type fg in your shell to resume the session exactly where you left off. This is not supported on Windows.

From the official Hermes Agent documentation.

Hermes Agent has been suspended. Run `fg` to bring Hermes Agent back.
