Use a skill auditor as its own test subject

An experimental loop tests another skill to evaluate and improve the auditor itself.

By @.salt555 · Discord

but if i run the skill-audit on the skill-audit skill itself then it just picks a random skill to improve

— @.salt555, 2026-04-23, via the public Nous Discord archive.

The contributor describes running a custom audit skill against itself. It chooses another skill as a test case, executes that skill in a sandbox, and uses the outcome to revise both the tested skill and the auditor. They schedule the experiment with cron.

Limitations: A community experiment, not a demonstrated guarantee of improvement. The source does not supply a complete implementation. Review proposed skill edits before using them; this is distinct from the built-in security audit command.

Documentation check: this specific community technique was not found in the official English reference snapshot (5458de9) or the cached prompt guides. Related built-in features are documented. This is a bounded source review, not a claim about every document or independent execution testing.
