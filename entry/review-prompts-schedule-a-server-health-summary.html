Schedule a server health summary

By Nous Research · Official Docs

Review disk, memory and container status on a recurring schedule.

Requires shell access on the intended host. Adjust the documented thresholds and check that the commands exist.
The prompt below is copied from the linked official example; replace placeholders before use.

Source: official Hermes Agent documentation. This card is an editorial summary; copyable examples retain source wording. Verify the linked instructions for your installed version.

Every 6 hours, check disk usage with 'df -h', memory with 'free -h',
and Docker container status with 'docker ps'. Report anything unusual —
partitions above 80%, containers that have restarted, or high memory usage.
