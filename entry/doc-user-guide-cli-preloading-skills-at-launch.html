Preloading Skills at Launch

From Official Docs

If you already know which skills you want active for the session, pass them at launch time: Hermes loads each named skill into the session prompt before the first turn. The same flag works in interactive mode and single-query mode.

From the official Hermes Agent documentation.

hermes -s hermes-agent-dev,github-auth
hermes chat -s github-pr-workflow -s github-auth
