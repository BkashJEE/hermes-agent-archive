obra/superpowers

Development skills with a native Hermes plugin installer.

By obra · GitHub

WHAT IT DOES
A development workflow built from reusable skills. The project documents a native Hermes plugin, so its coding practices can be used inside Hermes sessions.

HOW TO USE IT
Install the plugin with the command below, then restart active Hermes sessions. Start with a feature or bug and use the planning, testing and review workflow.

USE CASE
Turn a loosely described feature into an implementation plan, then work through changes and verification. This is an archive-authored example, not a quoted user report.

LIMITATION
The README notes that Hermes has no post-compaction hook for this plugin. Restart the session if skills stop triggering after a long conversation.

hermes plugins install obra/superpowers --enable
