Show HN: Comemo – composite memory provider for Hermes Agent

By Andassyn · Hacker News · November 16, 2026

There are many memory providers that can be used externally with Hermes Agent. However, like many other AI agents, Hermes only provides one slot for an external memory provider.

Comemo takes that slot and acts as a composite provider. How? It fans out memory writes to multiple backends such as Mem0, Honcho, and Supermemory. On retrieval, it queries the enabled providers, merges their results, and removes duplicates before returning them to Hermes.

I intend to add support for more memory providers and eventually extend Comemo to other open-source AI agents with similar limitations.

— Andassyn, 2026-11-16, posted to Hacker News.
