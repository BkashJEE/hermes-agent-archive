rlaope/oh-my-hermes

One plugin adding a coding layer, long-term memory and an operating layer on top of Hermes, without replacing it.

By rlaope · GitHub

WHY
The things people bolt onto Hermes — memory, coding conventions, a tighter operating loop — usually arrive as three separate installs. This bundles them.

HOW
A single install script: curl to sh on Unix, or the PowerShell equivalent on Windows. The project also publishes INSTALL_FOR_AGENTS.md pinned to a resolved commit SHA, so an agent can install it without being pointed at a moving branch.

USE CASE
You want the common add-ons configured together rather than assembled by hand.

Verified: the README's own line is "Install once. Keep Hermes. Add a stronger operating layer." Pinning the agent install doc to a commit is the project's own practice.
