Shopify

Query Shopify Admin/Storefront GraphQL APIs via curl.

From Official Docs

Work with Shopify stores directly through `curl`: list products, manage inventory, pull orders, update customers, read metafields. No SDK, no app framework — just the GraphQL endpoint and a custom-app access token.

Platforms: linux, macos, windows. Needs: curl, jq. Environment: SHOPIFY_ACCESS_TOKEN, SHOPIFY_STORE_DOMAIN.

hermes skills install official/productivity/shopify
