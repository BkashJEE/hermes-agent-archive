nesquena/hermes-webui

Hermes from a browser or a phone, claiming near parity with the CLI over an SSH tunnel.

By nesquena · GitHub

WHY
The CLI is fine at a desk and useless on a phone. This exposes the same agent through a web interface reachable from any device.

HOW
It uses your existing Hermes setup and models rather than asking for new configuration, and documents reaching it securely through an SSH tunnel. Native Windows setup is documented separately: Python 3.11+, then a virtualenv from the hermes-agent root.

USE CASE
Checking on a long-running session from a phone, or driving the agent from a machine that has no Hermes install of its own.

Verified: the README claims near 1:1 parity with the Hermes CLI and names the SSH tunnel as the access path. Parity is the author's claim, not a measurement.
