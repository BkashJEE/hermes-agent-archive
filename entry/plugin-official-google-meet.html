Google Meet

By Nous Research · Official Docs · Date unknown

Google Meet for Hermes: the agent joins a meet.google.com call you give it (meet_join), scrapes live captions into a transcript (meet_status, meet_transcript), can speak in the call in realtime mode (meet_say), leaves (meet_leave), and can run a transcribe-only bot on another machine through a remote node; `hermes meet setup|install|auth|join|node`. Explicit by design: it only joins URLs passed in, with no calendar scanning or auto-dial. Known limitation: a bot joined with meet_join leaves when that agent turn ends (hermes-official-plugins#518). Formerly built into Hermes core; existing users are migrated automatically. Disclosure: Python dependencies playwright and websockets; `hermes meet install` downloads Chromium through Hermes and, with --realtime, asks before running apt-get or brew for audio tools. The bot opens the Meet URL in headless Chromium, so Google Meet receives the guest name and the bot's camera and microphone (Chromium's fake devices in transcribe mode); `hermes meet join` (not the meet_join tool) signs in with a Google session you save via `hermes meet auth`, stored in your profile. Captions are scraped from the page into transcript.txt in the profile's meetings folder (on the remote node in remote mode, whose WebSocket returns requested transcript lines) and reach your model provider only as tool output. Realtime mode sends the session instructions, voice and each meet_say text to the OpenAI Realtime API (wss://api.openai.com) with HERMES_MEET_REALTIME_KEY or OPENAI_API_KEY and plays the returned speech into the call; meeting audio is never sent to OpenAI. A remote node is reached over a plain WebSocket (no TLS built in) with a shared token you approve.

Requires Hermes >=0.21.7. Platforms: linux, macos. Tools: meet_join, meet_leave, meet_status, meet_transcript, meet_say. Version 0.3.0 at import.
