Context Compression

From Official Docs

Long conversations are automatically summarized when approaching context limits: When compression triggers, middle turns are summarized while the first 3 and last 20 turns are always preserved.

From the official Hermes Agent documentation.

# In ~/.hermes/config.yaml
compression:
  enabled: true
  threshold: 0.50    # Compress at 50% of context limit by default

# Summarization model configured under auxiliary:
auxiliary:
  compression:
    model: ""  # Leave empty to use the main chat model (default). Or pin a cheap fast model, e.g. "google/gemini-3-flash-preview".
